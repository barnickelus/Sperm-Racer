Beaded Sombrero Actor — engine build

Built the way the racers in the game are built: real bead rings that follow each form rather than a lattice on a grid, batched into instanced meshes. Loads the repository’s own three.min.js — the exact build index.html uses — with no module loader, no CDN and no OrbitControls, so the model code lifts straight into makeBeadCell(). Simple animations: idle float, body sway, a hat that rocks and lags the lean, a travelling tail wave with cruise and sprint beats, and a blink.
